# Wholesale Operations & Procurement Skill

## Operations & PO Workflow
1. **Order Workflow**: Status progresses `Draft` -> `Submitted` -> `Reviewed` -> `Purchased` -> `Packed` -> `Dispatched` -> `Delivered` -> `Invoiced` -> `Paid`.
2. **Primary Supplier PO Generation**: Group order items by `ProductSupplier` primary vendor and generate `PurchaseOrder` records.
3. **Packing Slips**: Render HTML / PDF packing slips excluding price figures for warehouse packing staff.
